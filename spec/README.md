# spec — общий источник правды

Всё, что должно совпадать у клиента и сервера, лежит здесь.

| Файл | Кто использует |
| --- | --- |
| `loadline.schema.json` | Типы TS (`pnpm gen:model`), серверная валидация (встроенный ресурс `Loadline.Core`) |
| `presets/default.json` | Движок и приложение: μ, t₀, цена, hit ratio по типам компонентов |
| `scenarios/*.loadline.json` | Учебные сценарии в приложении и golden-тесты движка и сервера |
| `scenarios/*.expected.json` | Ожидаемые метрики сценариев, допуск ±2% |

## Правила

- Меняете схему — поднимаете `version`, если изменение несовместимое, и добавляете миграцию в `web/packages/engine/src/migrate.ts`.
- Меняете формулы или пресеты — перегенерируйте эталоны: `UPDATE_GOLDEN=1 pnpm --filter @loadline/engine test`, и объясните разницу в PR.
- Новый пресет — со ссылкой на бенчмарк в поле `source`.
