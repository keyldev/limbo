# ADR 0002. Схема хранится целиком в jsonb

Дата: 2026-10-02 · Статус: принято

## Контекст

Схема — граф из узлов и связей. Её можно хранить нормализованно (таблицы nodes, edges) или документом.

## Решение

Одна таблица `diagrams`, документ `.loadline.json` целиком в колонке `doc jsonb`. Сервер проверяет документ по `spec/loadline.schema.json` и не разбирает граф.

## Почему

- Схему всегда читают и пишут целиком. Запросов «найти все узлы типа cache» в MVP нет.
- Формат уже версионирован и описан JSON Schema: миграции живут в движке, а не в базе.
- Нет модели графа на C#, значит, нечего синхронизировать с TypeScript.

## Последствия

- Совместное редактирование (этап 4) будет работать на уровне операций над документом через SignalR, а хранить по-прежнему снимки.
- Если понадобится поиск по содержимому схем, Postgres умеет индексы GIN по jsonb.
