# ADR 0003. Библиотека доски

Дата: — · Статус: **открыто**, решение на неделе 2 (12–16 октября)

## Кандидаты

- [Foblex Flow](https://www.npmjs.com/package/@foblex/flow), MIT
- [ngx-vflow](https://www.npmjs.com/package/ngx-vflow), MIT

## Как выбираем

По дню на прототип каждой. Критерии:

| Критерий | Foblex Flow | ngx-vflow |
| --- | --- | --- |
| 60 fps при перетаскивании на 200 узлах | | |
| Связи порт-в-порт, переподключение связи | | |
| Свои шаблоны узлов (шкала загрузки, порты-ромбы) | | |
| Зум и панорамирование | | |
| Работает с Angular 22 без патчей | | |
| Живость репозитория: релизы и ответы в issues за полгода | | |

_Заполнить после прототипов._
