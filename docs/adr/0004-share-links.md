# ADR 0004. Ссылки на схему живут в хеше

Дата: 2026-10-02 · Статус: принято

## Контекст

Схемой нужно делиться ссылкой. Сервер умеет короткие ссылки (`POST /api/v1/diagrams` → slug), но фронт по плану лежит на статическом хостинге (Cloudflare Pages или GitHub Pages), а сервер может быть недоступен или вовсе не поднят.

## Решение

Два вида ссылок, оба в хеше адреса:

- `/#s=<slug>` — короткая. Схема хранится на сервере, ссылка ведёт на неё.
- `/#doc=1.<base64url>` — схема внутри ссылки: JSON → deflate-raw (встроенный в браузер `CompressionStream`) → base64url. `1.` — версия кодировки.

Кнопка «Ссылка» сначала пробует сервер. Если его нет (сеть, 404, 405, 5xx), делает ссылку со схемой внутри, но не длиннее 8000 символов. Схему больше этого предлагаем сохранить файлом. Ошибки, которые сервер вернул по существу (400, 413, 429), показываем как есть и не подменяем ссылкой без сервера.

Обе ссылки — снимки: правки после этого в ссылку не попадают. Токен правки от сервера хранится в браузере (`loadline.shared.v1`), чтобы позже можно было обновить или удалить ссылку.

После открытия ссылки хеш убирается из адреса. Дальше схема живёт в автосохранении (`loadline.autosave.v1`), и обновление страницы не откатывает правки к состоянию ссылки.

## Почему хеш, а не `/d/<slug>`

- Хеш не уходит на сервер статики, поэтому не нужна настройка SPA-фолбэка на каждом хостинге.
- Ссылка со схемой внутри может быть длинной. В хеше она не упирается в лимиты длины запроса у CDN и в логи сервера.
- Один разборщик для обоих видов ссылок, роутер не нужен. Angular Router из приложения убран: он перехватывал `hashchange` и возвращал хеш в адрес.

## Последствия

- С появлением лендинга доска живёт на `/app/`, и ссылки выглядят как `/app/#s=…` и `/app/#doc=…`. Лендинг на `/` переносит хеш `#s=`, `#doc=` и `#scenario=` на `/app/`, так что ссылки на корень тоже открываются. Тем же механизмом лендинг ссылается на учебные сценарии: `/app/#scenario=<имя>`.
- Ссылки `/#s=…` чуть длиннее, чем `/d/…`. Если понадобятся «красивые» ссылки, `/d/<slug>` можно добавить редиректом на `/#s=<slug>`.
- Данные из ссылки, файла и автосохранения проверяются на клиенте (`validateDocument` в движке) по тем же ограничениям, что и JSON Schema на сервере. Распаковка ссылки ограничена 256 КБ, как и тело запроса на сервере.
- В проде фронт и API на разных доменах. Адрес API вшивается при сборке константой `LOADLINE_API_URL` (`ng build --define`, см. `web/app/src/app/config/api-url.ts` и workflow `deploy-web.yml`), а домен фронта прописан в `Cors:Origins` сервера (`WEB_ORIGIN` в `deploy/.env`). Без константы клиент ходит на тот же origin (`/api`, в разработке — через прокси Angular).
